Featured Project

ChargerWhisper

ChargerWhisper is an Android utility application that monitors mobile battery charging levels. It alerts the user at selected charge percentages.


The application helps users to reduce overcharging, overheating and unnecessary power consumption.

Strict Mode

Continuous alert at selected levels such as 80%, 90% or 100%.

Smart Mode

Alert sounds only ten times and stops when charger is unplugged or application is closed.
